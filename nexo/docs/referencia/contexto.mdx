# 🧩 Contexto e respostas

Ao executar um comando, o Nexocord fornece um objeto de contexto (`ctx`) em vez de passar a interação diretamente para a função `run`.

O contexto centraliza o acesso à interação, ao cliente Discord e ao método de resposta, simplificando a implementação dos comandos.

## 🚀 Acessando o contexto

```ts
import { createCommand, CommandType } from "nexocord";

export default createCommand({
  name: "me",
  description: "Mostra o usuário.",
  type: CommandType.ChatInput,

  async run(ctx) {
    const user = ctx.interaction.user;

    console.log(ctx.client.user);

    await ctx.reply({
      content: `Você é ${user.tag}.`,
    });
  },
});
```

## 📦 Propriedades disponíveis

| Propriedade | Descrição |
| --- | --- |
| `ctx.interaction` | Interação original do Discord.js, tipada conforme o tipo do comando. |
| `ctx.client` | Cliente Discord utilizado pelo Nexocord. |
| `ctx.reply(options)` | Responde à interação, com suporte à preparação de Components V2. |

Você pode utilizar `ctx.interaction` sempre que precisar acessar propriedades ou métodos específicos da interação original.

## 💬 Respondendo a uma interação

Utilize `ctx.reply()` para responder ao comando. O método recebe as opções de resposta do Discord.js, incluindo propriedades como `content`, `embeds` e `flags`.

```ts
await ctx.reply({
  content: "Olá! 👋",
});
```

## 🔒 Respostas efêmeras

Para enviar uma resposta visível somente ao usuário que executou o comando, utilize `MessageFlags.Ephemeral`.

```ts
import { MessageFlags } from "nexocord";

await ctx.reply({
  content: "Somente você pode ver esta mensagem.",
  flags: MessageFlags.Ephemeral,
});
```

## 🧩 Components V2

O método `ctx.reply()` também permite enviar componentes por meio da propriedade `components`. Você pode informar um único `DisplayInput` ou uma lista de componentes.

```ts
import { createCommand, ui } from "nexocord";

export default createCommand({
  name: "painel",
  description: "Exibe um painel.",

  async run(ctx) {
    const components = [
      ui.text("## Meu painel"),
      ui.divider(),
      ui.text("Escolha uma opção."),
    ];

    await ctx.reply({ components });
  },
});
```

O Nexocord prepara os componentes e adiciona automaticamente a flag `MessageFlags.IsComponentsV2`.

**Importante:** mensagens com Components V2 não podem combinar `components` com `content` ou `embeds`. Se essas propriedades forem utilizadas juntas, `ctx.reply()` lançará um erro.

Para conhecer os componentes disponíveis e aprender a utilizá-los, consulte a página [Components V2](/docs/components-v2).

## 📎 Enviando arquivos

A propriedade `files` continua disponível e aceita os anexos compatíveis com o Discord.js.

```ts
import { AttachmentBuilder } from "discord.js";

const file = new AttachmentBuilder(
  Buffer.from("Relatório gerado."),
  { name: "relatorio.txt" },
);

await ctx.reply({
  content: "Seu arquivo está pronto.",
  files: [file],
});
```

Quando Components V2 é utilizado, os arquivos associados aos componentes são reunidos automaticamente com os arquivos informados em `files`.
