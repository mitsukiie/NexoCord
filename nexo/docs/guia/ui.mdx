# UI

A UI do Nexo facilita a criação do **Display Components V2** do Discord com tipagem, validação e renderização pronta para envio.

---

## 🚀 Como funciona

- 🧱 Você monta componentes com `ui.*`.
- 🎨 Converte tudo para Components V2 com `ui.render(...)`.
- ✉️ Envia com `ui.send(...)`.
- 📎 Arquivos de `ui.file(...)` são anexados automaticamente.
- ✅ Regras de tamanho/limites são validadas antes do envio.

:::info Fluxo recomendado
`ui.*` → `ui.render(...)` → `ui.send(...)`
:::

const { createCommand, CommandType, ui } = require("nexocord");

module.exports = createCommand({

## 🧰 Componentes

### 📝 Texto e separador

```ts
import { SeparatorSize, TextSize, ui } from "nexocord";

ui.text("Olá mundo");
ui.text(["Linha 1", "Linha 2"]);

ui.text("Título principal", { size: TextSize.Title });
ui.text("Subtítulo", { size: TextSize.Subtitle });
ui.text("Texto pequeno", { size: TextSize.Small });

ui.text("Negrito", { bold: true });
ui.text("Itálico", { italic: true });
ui.text("Sublinhado", { underline: true });
ui.text("Combinado", { bold: true, italic: true, underline: true });

ui.text.list(["Item A", "Item B"]);
ui.text.ordered(["Primeiro", "Segundo"]);
ui.text.code("bun run dev");
ui.text.quote(["Linha citada 1", "Linha citada 2"]);
ui.text.spoiler("conteúdo oculto");

ui.separator({ spacing: SeparatorSize.Small, divider: true });
ui.separator();
```

`ui.divider()` ainda existe como alias deprecated de `ui.separator()`. Prefira `ui.separator()` nos exemplos novos.

`ui.text(...)` aceita `string` e `string[]`.

Helpers disponíveis no builder:

- `ui.text.list(...)`: lista com `- item`
- `ui.text.ordered(...)`: lista numerada (`1. item`)
- `ui.text.code(...)`: inline code com crases automáticas
- `ui.text.quote(...)`: citação (`> texto`)
- `ui.text.spoiler(...)`: spoiler (`||texto||`)

Opções de estilo:

- `size`: use `TextSize.Title | TextSize.Subtitle | TextSize.Section | TextSize.Small`
- `bold`, `italic`, `underline`: aplicam formatação markdown no conteúdo

:::tip Recomendado no TypeScript
Prefira `TextSize` e `SeparatorSize` em vez de valores numéricos para deixar o código mais legível e com autocomplete melhor.
:::

### 🔘 Botão / Row

```ts
import { ButtonStyle } from "discord.js";

ui.row(
  ui.button({
    label: "Confirmar",
    customId: "confirm:id",
    style: ButtonStyle.Primary,
  }),
  ui.button({
    label: "Cancelar",
    customId: "cancel:id",
    style: ButtonStyle.Danger,
  }),
);
```

:::tip Dica
`emoji` também é aceito em `ui.button({ ..., emoji: '✅' })`.
:::

### 📚 Select Menus

Os builders aceitam dois estilos de chamada:

- `ui.select.user("select:user", { placeholder: "Selecione usuário" })`
- `ui.select.user({ customId: "select:user", placeholder: "Selecione usuário" })`

```ts
import { ChannelType } from "discord.js";

ui.row(
  ui.select.string(
    "select:id",
    [
      { label: "Opção A", value: "a" },
      { label: "Opção B", value: "b" },
    ],
    { placeholder: "Escolha..." },
  ),
);

ui.row(ui.select.user("select:user", { placeholder: "Selecione usuário" }));
ui.row(
  ui.select.user({ customId: "select:user", placeholder: "Selecione usuário" }),
);

ui.row(ui.select.role("select:role", { placeholder: "Selecione cargo" }));
ui.row(
  ui.select.role({ customId: "select:role", placeholder: "Selecione cargo" }),
);

ui.row(ui.select.channel("select:channel", [ChannelType.GuildText]));
ui.row(
  ui.select.channel({
    customId: "select:channel",
    channelTypes: [ChannelType.GuildText],
    placeholder: "Selecione canal",
  }),
);

ui.row(ui.select.mentionable("select:mentionable"));
ui.row(ui.select.mentionable({ customId: "select:mentionable" }));

ui.row(
  ui.select.string({
    customId: "select:string",
    options: [
      { label: "Opção A", value: "a" },
      { label: "Opção B", value: "b" },
    ],
    placeholder: "Escolha...",
  }),
);
```

### 🧱 Section e thumbnail

```ts
ui.section(["Linha 1", "Linha 2"], {
  button: ui.button({ label: "Abrir", customId: "open:id" }),
});

ui.section(["Linha 1"], {
  thumbnail: ui.thumbnail({
    url: "https://picsum.photos/id/1003/300/300",
    description: "Miniatura",
  }),
});
```

:::info Importante
Agrupa 1 a 3 textos com um botão **ou** miniatura acessória (não os dois).
:::

### 🖼️ Gallery e imagem

ui.gallery(

ui.image({

### 📎 Arquivos

```ts
import { AttachmentBuilder } from "discord.js";

const file = new AttachmentBuilder(Buffer.from("conteudo"), {
  name: "exemplo.txt",
});
ui.file.fromAttachment(file); // gera attachment://exemplo.txt automaticamente
```

### 📦 Container

```ts
import { ui } from "nexocord";

ui.container(
  { color: "#0099ff" },
  ui.text("## Título"),
  ui.separator(),
  ui.row(ui.button({ label: "OK", customId: "ok" })),
);
```

:::tip Dica
Aceita `color` opcional nos formatos: `"#0099ff"`, `"0x0099ff"` ou `0x0099ff`.
:::

## 📋 Limites e validações

**Limites de tamanho:**

- 📏 Máximo **40 componentes** por mensagem
- 🔤 Texto: até **4.000 caracteres** por bloco
- 🔘 Rótulo de botão: **1-80 caracteres**
- 📚 Placeholder de select: até **150 caracteres**

**Estrutura de componentes:**

- 🔘 `customId` de botão/select: **1-100 caracteres**
- 📐 `ui.row(...)`: **1-5 componentes** por linha
- 🚫 Select não pode ficar junto de outros componentes na mesma row
- 📚 String select: **1-25 opções** no máximo

**URLs e arquivos:**

- 🖼️ Gallery: **1-10 itens**
- 🌐 URLs de mídia: devem começar com `http://` ou `https://`
