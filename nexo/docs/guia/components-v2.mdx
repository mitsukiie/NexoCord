# 🧩 Components V2

O NexoCord oferece builders declarativos para enviar Components V2 do Discord.
Os componentes são passados em `interaction.reply`, `followUp`, `editReply` ou
`update` por meio da interação estendida recebida no comando.

Você pode obter a API `ui` de duas formas:

- No callback `run`, receba `{ ui }` como terceiro argumento.
- Em qualquer módulo, importe `ui` de `nexocord/ui`.

As duas formas fornecem a mesma API. O exemplo abaixo usa a injeção disponível
no `run`:

## Exemplo completo

```ts
import { ButtonStyle, CommandType, createCommand } from 'nexocord';

export default createCommand({
  name: 'painel',
  description: 'Exibe um painel interativo.',
  type: CommandType.ChatInput,
  async run(interaction, client, { ui }) {
    await interaction.reply({
      components: [
        ui.container(
          ui.text('## Meu painel'),
          ui.text('Escolha uma opção:'),
          ui.row(
            ui.button({
              customId: 'painel/abrir',
              label: 'Abrir',
              style: ButtonStyle.Primary,
            }),
          ),
        ),
      ],
    });
  },
});
```

Quando a resposta contém componentes declarativos, o NexoCord prepara os
builders e aplica automaticamente a flag de Components V2. Não misture
Components V2 com `content` ou `embeds` na mesma resposta.

## Texto

Quando estiver fora de um callback de comando, importe a API pelo subpath:

```ts
import { SeparatorSize, TextSize, ui } from 'nexocord/ui';

const title = ui.text('Olá!', { size: TextSize.Title });
```

```ts
ui.text('Olá!');
ui.text(['Linha 1', 'Linha 2']);
ui.text('Título', { size: TextSize.Section, bold: true });
```

Também estão disponíveis `ui.text.list(items)`, `ui.text.ordered(items)`,
`ui.text.code(content)`, `ui.text.quote(content)` e
`ui.text.spoiler(content)`.

Os tamanhos disponíveis em `TextSize` são `Title`, `Subtitle`, `Section` e
`Small`. Você também pode informar diretamente os valores `1`, `2`, `3` ou `4`.

## Separadores

```ts
ui.separator();
ui.separator({ spacing: SeparatorSize.Large, divider: true });
ui.divider(); // alias de separator()
```

`SeparatorSize.Small` e `SeparatorSize.Large` representam os espaçamentos
disponíveis para separadores. O campo `divider` controla se a linha divisória
será exibida.

## Botões

Botões de interação usam `customId`. Botões de link usam `url` e não recebem
`customId`.

```ts
import { ButtonStyle } from 'nexocord';

ui.button({
  customId: 'painel/abrir',
  label: 'Abrir',
  style: ButtonStyle.Primary,
});

ui.button({
  label: 'Documentação',
  url: 'https://nexocord.vercel.app',
});
```

## Linhas de ação

Passe os componentes como argumentos de `ui.row`, não como um array. Uma linha
pode conter botões ou um único menu de seleção.

```ts
ui.row(
  ui.button({
    customId: 'confirmar',
    label: 'Confirmar',
    style: ButtonStyle.Success,
  }),
  ui.button({
    customId: 'cancelar',
    label: 'Cancelar',
    style: ButtonStyle.Danger,
  }),
);
```

## Menus de seleção

```ts
ui.select.string(
  'idioma',
  [
    { label: 'Português', value: 'pt' },
    { label: 'English', value: 'en' },
  ],
  {
    placeholder: 'Escolha um idioma',
  },
);

ui.select.user('membro', { placeholder: 'Escolha um usuário' });
ui.select.role('cargo');
ui.select.mentionable('entidade');
ui.select.channel('canal');
```

Também é possível passar um objeto completo:

```ts
ui.select.string({
  customId: 'idioma',
  options: [{ label: 'Português', value: 'pt' }],
});
```

Um menu de seleção é tratado por um responder com o tipo correspondente.

## Seções, imagens e arquivos

Uma seção recebe de um a três textos e pode ter um botão ou uma miniatura como
acessório, mas não os dois ao mesmo tempo.

```ts
ui.section(['## Perfil', 'Informações do usuário'], {
  thumbnail: ui.thumbnail({ url: 'https://example.com/avatar.png' }),
});
```

Para galerias, crie cada item com `ui.image` e passe-os como argumentos:

```ts
ui.gallery(
  ui.image({ url: 'https://example.com/imagem.png' }),
  ui.image({ url: 'https://example.com/outra.png' }),
);
```

Arquivos podem referenciar um anexo:

```ts
import { AttachmentBuilder } from 'discord.js';

const attachment = new AttachmentBuilder('./relatorio.pdf', {
  name: 'relatorio.pdf',
});

ui.file.fromAttachment(attachment);
// ou:
ui.file('attachment://relatorio.pdf');
```

Os anexos usados dentro dos componentes são incluídos automaticamente na
resposta. Arquivos adicionais ainda podem ser enviados na propriedade `files`.

## Containers

`ui.container` agrupa componentes. As opções podem ser passadas como primeiro
argumento:

```ts
ui.container({ color: '#5865F2' }, ui.text('## Configurações'), ui.separator());
```

## Respostas tradicionais

A interação estendida continua aceitando respostas tradicionais do Discord.js:

```ts
await interaction.reply({ content: 'Resposta normal' });
await interaction.followUp({ content: 'Outra mensagem' });
```

Para Components V2, use `components` e não informe `content` nem `embeds`.
