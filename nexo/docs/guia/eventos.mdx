# 🎧 Eventos

Os eventos permitem executar código quando algo acontece no Discord, como quando o bot fica online, um usuário entra em um servidor ou uma mensagem é enviada.

Use `createEvent()` para definir um evento. Os arquivos são carregados recursivamente a partir do diretório configurado em `directories.events` e devem exportar o evento como `default`.

## 🚀 Exemplo

```ts
import { createEvent, Events } from "nexocord";

export default createEvent({
  name: Events.ClientReady,
  once: true,

  run(client) {
    console.log(`${client.user.displayName} online.`);
  },
});
```

Neste exemplo, o evento é executado quando o cliente fica pronto. Como `once` está definido como `true`, o listener é executado apenas uma vez.

## 📋 Campos do evento

| Campo | Tipo | Obrigatório | Descrição |
| --- | --- | --- | --- |
| `name` | `keyof ClientEvents` | Sim | Nome do evento do Discord.js. |
| `once` | `boolean` | Não | Define se o listener será executado apenas uma vez. O padrão depende da implementação do Nexocord. |
| `run` | `function` | Sim | Função executada quando o evento acontece. |

## ⚙️ Argumentos de `run`

A função `run` recebe os argumentos originais do evento do Discord.js, na mesma ordem, e o cliente como último argumento.

Os argumentos variam conforme o evento. Por exemplo, `ClientReady` recebe o cliente, enquanto eventos de mensagens recebem os dados relacionados à mensagem.

## 📚 Eventos disponíveis

O Nexocord exporta `Events` como uma reexportação de `discord.js`. Você pode utilizá-lo para referenciar os eventos sem precisar escrever seus nomes manualmente.

```ts
import { Events } from "nexocord";

Events.ClientReady;
Events.MessageCreate;
Events.InteractionCreate;
```

Consulte a [documentação do Discord.js](https://discord.js.org/docs/packages/discord.js/main/Events:Enum) para ver os eventos disponíveis.

## 💡 Dicas

- 🎯 Utilize `Events` para evitar erros ao escrever nomes de eventos manualmente.
- 🧩 Mantenha cada evento em seu próprio arquivo para facilitar a organização.
- 🔁 Use `once: true` quando o evento precisar ser executado apenas uma vez.
- 📂 Confira se o caminho configurado em `directories.events` corresponde à localização dos seus arquivos.
