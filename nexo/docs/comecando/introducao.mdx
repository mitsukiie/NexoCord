# Nexocord

Crie bots para Discord com TypeScript ou JavaScript usando o Discord.js e uma estrutura organizada para comandos, eventos, responders e Components V2.

## 🧭 O que é o Nexocord?

O Nexocord é um framework construído sobre o Discord.js que oferece uma estrutura organizada, carregamento automático e uma CLI integrada para simplificar o desenvolvimento de bots para Discord.

:::info 
A versão 3.0.0 traz melhorias, correções e mudanças na configuração do NexoCord.

Na versão 2.0.0, alguns usuários podem ter enfrentado problemas relacionados à tipagem do TypeScript. Peço desculpas pelos transtornos e agradeço a todos que tiveram paciência durante esse processo.

Se você já utiliza o NexoCord, consulte o [guia de migração](/docs/migration) antes de atualizar.
:::

## ✨ Por que usar o Nexocord?

- ⚡ **Configuração rápida** — comece a desenvolver sem configurar tudo manualmente.
- 🧱 **Estrutura organizada** — mantenha seu projeto preparado para crescer.
- 🧰 **CLI integrada** — crie projetos novos ou configure projetos existentes.
- 🔌 **Suporte a Node.js e Bun** — escolha o runtime que melhor atende ao seu projeto.
- 🧠 **Carregamento automático** — organize comandos e eventos sem precisar registrá-los manualmente um por um.

## 🎯 Para quem é o Nexocord?

- Desenvolvedores que estão começando a criar bots para Discord.
- Projetos que precisam de uma estrutura organizada e fácil de manter.
- Desenvolvedores que querem reduzir a configuração inicial e focar na implementação das funcionalidades.

## 📦 O que você vai encontrar aqui?

- Como instalar e configurar o Nexocord.
- Como criar e executar seu primeiro bot.
- Como criar comandos e definir opções.
- Como responder a interações e utilizar Components V2.
- Como utilizar a CLI com Node.js ou Bun.

## ⚡ Comece rápido

Novo por aqui? Siga o guia de [Instalação](/docs/installation) e depois crie seu [Primeiro Bot](/docs/first-bot).

Se você já possui um projeto, consulte a documentação da [CLI](/docs/cli) para configurá-lo com `nexo init`.

## ⚠️ Requisitos

- Node.js 20 ou superior, ou Bun em uma versão compatível com as dependências do projeto.
- Um aplicativo e bot criados no [Discord Developer Portal](https://discord.com/developers/applications).
- Um token armazenado em uma variável de ambiente. Nunca coloque seu token diretamente no código ou em um repositório público.

## Caminho recomendado
