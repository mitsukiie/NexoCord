# Nexocord

Crie bots para Discord com TypeScript ou JavaScript usando o Discord.js e uma
estrutura pronta para organizar comandos, eventos, responders e Components V2.

## 🧭 O que é o Nexocord?

O Nexocord é um framework construído sobre o Discord.js para tornar o
desenvolvimento de bots mais simples desde o primeiro arquivo. Ele cuida da
estrutura inicial do projeto, encontra e carrega seus comandos e eventos e
oferece uma CLI para criar projetos ou configurar aplicações existentes.

Assim, você pode começar rapidamente e manter o código organizado à medida que
o bot cresce, sem abrir mão dos recursos disponíveis no Discord.js.

## ✨ Por que usar o Nexocord?

- ⚡ **Configuração rápida** — comece a desenvolver sem configurar tudo manualmente.
- 🧱 **Estrutura organizada** — mantenha seu projeto preparado para crescer.
- 🧰 **CLI integrada** — crie projetos novos ou configure projetos existentes.
- 🔌 **Suporte a Node.js e Bun** — escolha o runtime que melhor atende ao seu projeto.
- 🧠 **Carregamento automático** — organize comandos e eventos sem precisar registrá-los manualmente um por um.


## 🎯 Para quem é o Nexocord?

O Nexocord é útil tanto para quem está criando seu primeiro bot quanto para
quem precisa manter um projeto maior organizado. Ele reduz o trabalho de
configuração inicial e deixa você concentrar seu tempo nas funcionalidades que
quer oferecer aos usuários.

## 📚 O que você vai encontrar nesta documentação?

Aqui você encontrará instruções práticas para:

- Instalar e configurar o Nexocord.
- Criar e executar seu primeiro bot.
- Criar comandos, opções e autocomplete.
- Reagir a eventos do Discord.
- Responder a interações com responders.
- Criar mensagens tradicionais e Components V2.
- Usar a CLI com Node.js ou Bun.

## ⚡ Comece rapidamente

Se você está começando um projeto novo, siga o guia de [Instalação](/docs/installation)
e depois acompanhe o passo a passo do [Primeiro Bot](/docs/first-bot).

Se já possui um projeto com `package.json`, use `nexo init` para configurá-lo.
A [referência da CLI](/docs/cli) explica a diferença entre criar um projeto
novo com `nexo create` e preparar um projeto existente com `nexo init`.

## ⚠️ Requisitos

Antes de começar, você precisará de:

- Node.js 20 ou superior, ou Bun compatível com as dependências do projeto.
- Um aplicativo e um bot criados no [Discord Developer Portal](https://discord.com/developers/applications).
- Um token armazenado em uma variável de ambiente.

Nunca coloque o token diretamente no código nem o envie para um repositório
público.

## 🗺️ Caminho recomendado

1. [Instale o Nexocord](/docs/installation).
2. Crie um projeto com `nexo create` ou configure um projeto existente com
   `nexo init`.
3. Execute seu [Primeiro Bot](/docs/first-bot).
4. Aprenda a criar [Comandos](/docs/commands) e [Opções](/docs/options).
5. Explore [Responders](/docs/responders) e [Components V2](/docs/components-v2).
