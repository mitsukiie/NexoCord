# Primeiro bot

Nesta página, você vai criar um bot simples com Nexocord, configurar o token do Discord e entender como funcionam os comandos e eventos.

## Criar o projeto

Use a CLI para gerar a estrutura inicial:

```bash
nexo create meu-bot
cd meu-bot
nexo dev
```

O assistente solicitará o runtime (**Node.js ou Bun**) e a linguagem (**TypeScript ou JavaScript**).


## Configurar o token

Crie um arquivo `.env` na raiz do projeto:

```env
TOKEN=seu-token-do-discord
```

Nunca compartilhe seu token nem o envie para um repositório público. Adicione `.env` ao `.gitignore`.

## Estrutura do projeto

O template TypeScript inclui uma estrutura semelhante a esta:

```text
src/
├── commands/
│   └── utils/
│       └── ping.ts
├── events/
│   └── ready.ts
└── index.ts
```

Em JavaScript, os arquivos equivalentes utilizam a extensão `.js`.

## Inicialização do bot

No arquivo de entrada, `src/index.ts`, configure a inicialização do Nexocord:

```ts title="src/index.ts"
import { Bootstrap, GatewayIntentBits } from "nexocord";

await Bootstrap.init({
  token: process.env.TOKEN,
  intents: [GatewayIntentBits.Guilds],
});
```

Os diretórios padrão são `src/commands` e `src/events`. Para alterá-los, crie um arquivo `nexocord.json` ou `nexocord.config` na raiz do projeto. Consulte o guia de [Configuração](/docs/configuration).

Em JavaScript, use o mesmo código em `src/index.js`. O template gerado configura o projeto para utilizar ESM.

## Criar um comando

Crie o arquivo `src/commands/utils/ping.ts`:

```ts title="src/commands/utils/ping.ts"
import { CommandType, createCommand } from "nexocord";

export default createCommand({
  name: "ping",
  description: "Responde com Pong.",
  type: CommandType.ChatInput,
  async run(ctx) {
    await ctx.reply({ content: "Pong!" });
  },
});
```

## Criar um evento

Crie o arquivo `src/events/ready.ts`:

```ts title="src/events/ready.ts"
import { createEvent, Events } from "nexocord";

export default createEvent({
  name: Events.ClientReady,
  once: true,
  run(client) {
    console.log(`${client.user.displayName} online.`);
  },
});
```

Os arquivos de comandos e eventos devem exportar seus objetos usando `default`. O Nexocord carrega esses arquivos durante a inicialização feita por `Bootstrap.init`, sem exigir o registro manual de cada comando.

## Executar em produção

No projeto TypeScript, compile o código antes de iniciar o bot.

### CLI

```bash
nexo build
nexo start
```

### Node.js com npm

```bash
npm run build
npm run start
```

### Bun

```bash
bun run build
bun start
```

Os comandos e scripts disponíveis podem variar conforme o template e o runtime escolhidos.
