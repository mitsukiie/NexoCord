# NexoCord V3.2.3

## Interactions

O método `interaction.reply` agora aceita a opção `withResponse`.

Use `withResponse: true` quando precisar receber o `InteractionCallbackResponse`
retornado pelo Discord.js:

```ts
await interaction.reply({
  content: 'Resposta enviada!',
  withResponse: true,
});
```

Quando `withResponse` não for informado ou for definido como `false`, o método
mantém o comportamento padrão e não retorna uma resposta da interação.
