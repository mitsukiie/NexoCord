# __PROJECT_NAME__

Projeto criado com [NexoCord](https://www.npmjs.com/package/nexocord), um framework para bots Discord baseado em discord.js.

## Requisitos

- Node.js 20+ ou Bun
- Token de um bot criado no [Discord Developer Portal](https://discord.com/developers/applications)

## Configuração

1. Preencha a variável `TOKEN` no arquivo `.env`.
2. Personalize as opções em `nexocord.json`, se necessário.

## Scripts

- `bun dev` — inicia o bot em modo de desenvolvimento.


## Documentação

Consulte a [documentação do NexoCord](https://nexocord.vercel.app/) para aprender a criar comandos, eventos e usar os recursos do framework.
